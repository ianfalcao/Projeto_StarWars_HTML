# Arquivos da Galáxia

Site acadêmico sobre o universo de Star Wars, desenvolvido por Ian Falcão para a disciplina de Desenvolvimento Front-End para Web.

## Sobre o projeto

O site reúne informações sobre a cronologia da saga, Jedi, Sith, naves, planetas, facções e caçadores de recompensas. Também conta com um guia de mídias e um formulário de recrutamento temático.

Desenvolvido em HTML5, com elementos semânticos, links, imagens, áudio, vídeo e campos de formulário.

## Estrutura

```text
html/main/   — Página inicial (index.html)
html/pages/  — Páginas de conteúdo
img/         — Imagens
audio/       — Arquivos de áudio
video/       — Arquivos de vídeo
```

## Como abrir

1. Abra a pasta raiz do projeto no VS Code.
2. Com a extensão Live Server instalada, clique com o botão direito em `html/main/index.html` e selecione **Open with Live Server**.
3. Use o menu de navegação para explorar as páginas.

Execute o servidor a partir da raiz do projeto para que os caminhos de imagens, áudios e vídeos funcionem corretamente.

Projeto de fã para fins educacionais, sem vínculo oficial com Star Wars.
